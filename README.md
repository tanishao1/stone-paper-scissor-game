# 🎮 Stone Paper Scissor Game

A simple **Stone Paper Scissor game** built using Python and Tkinter. The player plays against the computer with random moves and score tracking.

## ✨ Features
- GUI using Tkinter  
- Player vs Computer  
- Score tracking  
- Reset option  

## 🛠 Tech Used
- Python  
- Tkinter  

## 🚀 Run
```bash
python main.py
